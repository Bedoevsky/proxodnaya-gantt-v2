# Проходная · Диаграмма Ганта · Интерактивный план V2

Интерактивная диаграмма Ганта учебного проекта «Проходная» — вторая версия плана, рядом с [прежней](https://proxodnaya-gantt.comfytamarind2.chatgpt.site/). Ссылка на неё стоит в [расписании проекта](https://github.com/druni-bratani/proxodnaya/blob/main/docs/schedule.md).

**Открыть:** [bedoevsky.github.io/proxodnaya-gantt-v2](https://bedoevsky.github.io/proxodnaya-gantt-v2/)

## Что умеет

- **Пакеты и разделы ИСР** со сроками, ответственными и критериями готовности; вехи M1–M4 стоят на шкале.
- **Режим «Операции»**: 84 операции по часам в окне 10:00–16:00 МСК — исполнитель, входы, результат и очередь исполнителя.
- **Критический путь**: расчёт методом CPM от вехи M4, фокус на пути и на любом из маршрутов одинаковой длины.
- **Связи**: полоса без красной обводки имеет резерв; при наведении подсвечиваются предшественники и последователи.
- Цвет по разделам или по исполнителям, фильтр по исполнителю, масштаб, тёмная тема, печать на А4.
- **Ссылка на любую строку**: `#4.3`, `#4.3.2`, `#M2` — открывает диаграмму с выбранной работой.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html`, `styles.css`, `app.js` | Страница диаграммы. Без сборки и внешних зависимостей |
| `model.js` | Разбор снимка, расчёт резерва и критического пути |
| `data.js` | Снимок плана. Генерируется скриптом, вручную не правится |
| `sync-data.mjs` | Сборка снимка из реестров основного репозитория |
| `test/model.test.mjs` | Проверки модели и снимка |

## Открыть локально

Откройте `index.html` в браузере — сервер не нужен. Для публикации достаточно выложить папку как статический сайт: в GitHub Pages — ветка `main`, каталог `/`.

## Обновить данные

Снимок собирается из `project-backlog.csv` и `work-plan.csv` основного репозитория:

    node sync-data.mjs ../proxodnaya/docs
    node --test

Тесты сверяют расчёт с числами из `docs/schedule.md` и `docs/wbs.md`. Если реестры изменились и тест упал — обновите и документацию.

Номера карточек доски для разделов, пакетов и вех хранятся в `CARD_ISSUES` скрипта: в реестрах их нет.
